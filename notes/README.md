# 주제별 학습 노트

학습 종료 시 templates/topic-note.md를 참고해 실제 다룬 내용과 답변을 기록한다. 파일 이름은 `ARCH-03-computer-components.md`처럼 ID로 시작한다. 초기 진단에서 맞혔어도 반드시 학습한다. 현재 컴퓨터구조·운영체제의 실제 학습·연결 설명 노트가 있다. 상태는 tracking/progress.md에서 관리한다.

## 복습 정리본

주제 노트에는 실제 답변·교정·출처·남은 목표를 보존한다. summaries/의 정리본은 핵심 개념을 빠르게 찾아보는 자료이며 학습자 답변이나 진도 증거를 대체하지 않는다. 복습 범위를 예고한 뒤 질문 하나에 먼저 답하고 정리본과 대조한다. 새로운 챕터의 개념 설명과 시연은 확인 질문보다 먼저 진행한다.

시각 자료는 Mermaid에 한정하지 않고 구조도·단계별 그림·표·필요한 조작형 자료를 활용한다. 수업 중 필요한 임시 자료 생성과 학습 종료 시 정리본·답변 기록을 구분하며, 시각 자료의 가정과 출처도 보존한다.
