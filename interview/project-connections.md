# 프로젝트와 CS 연결

기본 CS를 해당 프로젝트에 등장한 기술만으로 제한하지 않는다. 학습한 원리를 적용할 수 있는 사례로 활용한다. 기존 포트폴리오와 코드를 실제로 확인하기 전에는 구현 사실을 만들어 채우지 않는다.

프로젝트 하나당 다음을 학습자에게 하나씩 질문한다.

1. 해결할 문제와 자신의 구현 범위.
2. 선택한 구조와 다른 대안의 차이.
3. 공유 자원·요청·상태·저장·전달의 경계.
4. 순서 변경·중복·타임아웃·부분 실패가 생기면 남는 상태.
5. 실제로 테스트하거나 측정한 것과 아직 가설인 것.
6. 제약·한계와 개선 시 필요한 비용.

아직 프로젝트별 검증 결과는 없다. 다른 채팅에서 코드나 포트폴리오 접근이 필요해지면 공개 링크 또는 접근 가능한 자료를 기준으로 확인한다.
