# 면접 복습

전체 범위에서 정의·원리·선택·조건 변화 질문을 섞어 연습한다. 회사별 출제 확률을 단정하거나 특정 진단 문항만 대비하지 않는다. 모르는 질문은 아는 범위·가정·미확인 부분을 구분해 설명하는 연습도 한다.

챕터의 개념·원리와 교사 예시·원문을 학습한 뒤 확인 구간에서 면접형 질문을 사용한다. 직접 고른 프로그램으로 개념을 연결하는 통합 질문을 기본으로 하며 특정 문항 수를 완료 기준으로 삼지 않는다. 답변을 마칠 때까지 기다리고 내용의 정확성·가정·조건과 전달 순서·예시의 연결을 나누어 피드백한다. 답변 구성은 정의→차이·원리→예시→적용 조건을 연습한다.

학습 중 나온 질문은 종료 시 해당 노트에 보존하고 이 폴더는 복습용 링크와 연습 결과만 관리한다. 최초 모의 면접도 실제 수행한 뒤 세션 기록을 연결한다.
