# 소프트웨어·보안

기초 회차의 필수 영역이다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: DEVJAVA, JUNIT, OWASP, SPRING. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| SE-01 | 책임과 설계 경계 | 관심사 분리, 결합도·응집도, 변경 이유 | 클래스를 나누기만 하면 결합도가 낮아지는가? |
| SE-02 | 추상화와 의존성 | 인터페이스, 의존성 주입, 대표 설계 원칙의 목적과 비용 | 추상화를 추가할수록 유지보수가 쉬워지는가? |
| SE-03 | 테스트 범위 | 단위·통합·E2E, 테스트 대역, 무엇을 검증하는지 | 클래스 하나를 테스트해도 통합 테스트일 수 있는가? |
| SE-04 | 테스트 설계와 신뢰성 | 경계·실패·동시성·회귀, 결정성, 커버리지의 한계 | 코드 커버리지 100%가 정확성을 보장하는가? |
| SE-05 | 인터페이스와 API 계약 | 입력 검증, 오류 표현, 호환성, REST의 기초 | 같은 성공 코드라도 호출자가 실패를 경험할 수 있는가? |
| SE-06 | 인증과 인가 | 신원 확인과 권한, 자원 단위 접근 통제, 최소 권한 | 로그인한 사용자라도 다른 사람의 데이터 접근을 막아야 하는가? |
| SE-07 | 세션과 토큰 | 쿠키 속성, 세션·토큰, 만료·폐기, JWT의 서명과 암호화 구분 | 서명된 토큰의 내용을 누구나 읽을 수 있는가? |
| SE-08 | 암호화·해시·비밀번호 | 대칭·비대칭 암호, 해시·서명, salt와 비밀번호 해싱 | 일반 해시 함수를 한 번 적용하면 비밀번호 저장에 충분한가? |
| SE-09 | 웹 입력과 브라우저 보안 | SQL injection·XSS·CSRF, 동일 출처·CORS, 방어 원칙 | CORS 설정만으로 인증이나 CSRF 방어가 되는가? |
| SE-10 | 오류와 재시도 | 실패 분류, 타임아웃, 재시도·백오프, 멱등성의 필요성 | 타임아웃 이후 무조건 재시도하면 어떤 중복이 생기는가? |
| SE-11 | 형상·배포·설정 관리 | Git 변경 이력, 코드 리뷰, CI의 취지, 설정·비밀 분리 | 빌드가 성공해도 배포 후 실패할 수 있는 이유는? |
| SE-12 | 관찰과 문제 해결 | 로그·지표·트레이스, 상관관계와 원인, 측정 가정 | 에러 로그가 없으면 서비스가 정상이라고 판단할 수 있는가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
