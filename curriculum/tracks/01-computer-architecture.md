# 컴퓨터구조

기초 회차의 필수 영역이다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: CS50, MIT-ARCH. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| ARCH-01 | 데이터 표현과 논리 | 비트·바이트, 진법, 부호와 정수 범위, 기본 논리 연산 | 정수 범위를 넘으면 어떤 일이 생기는가? |
| ARCH-02 | 실수와 문자 표현 | 부동소수점의 근사, Unicode와 문자 인코딩 | 0.1을 더한 결과가 예상과 다를 수 있는 이유는? |
| ARCH-03 | 컴퓨터의 구성 | CPU, 레지스터, RAM, 저장장치, 버스의 역할 | SSD가 빨라져도 RAM이 필요한 이유는? |
| ARCH-04 | 명령 실행 | 명령어, 인출·해독·실행, 프로그램 카운터 | 소스 코드 한 줄과 기계 명령 하나가 같은가? |
| ARCH-05 | 컴파일과 실행 | 컴파일·링크·로딩, 인터프리터와 JIT의 구분 | 컴파일을 거친 프로그램도 실행 중 최적화할 수 있는가? |
| ARCH-06 | 메모리 계층과 지역성 | 레지스터·캐시·RAM·저장장치, 시간·공간 지역성 | 배열을 순서대로 읽는 것이 유리한 이유는? |
| ARCH-07 | CPU 캐시 | 캐시 라인, hit·miss, 기본 교체·쓰기 정책 | 캐시를 무한히 크게 만들지 않는 이유는? |
| ARCH-08 | CPU 병렬성과 성능 | 코어·논리 프로세서, 파이프라이닝의 취지, 직렬 부분의 한계 | 코어 수를 두 배로 늘리면 두 배 빨라지는가? |
| ARCH-09 | 장치와 데이터 이동 | 인터럽트, 폴링, DMA, 장치 대기 | CPU가 직접 모든 데이터 복사를 담당해야 하는가? |
| ARCH-10 | 성능 해석 | 지연 시간·처리량, 병목, 단위와 측정 조건 | 처리량 증가가 개별 요청 지연 감소를 뜻하는가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
