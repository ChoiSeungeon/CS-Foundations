# 운영체제

기초 회차의 필수 영역이다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: OSTEP. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| OS-01 | 운영체제와 시스템 호출 | 커널·사용자 모드, 보호, 시스템 호출 | 파일 읽기를 일반 함수 계산과 똑같이 취급할 수 있는가? |
| OS-02 | 프로그램·프로세스·스레드 | 실행 인스턴스, 자원 소유, 공유·독립 영역 | 스레드끼리 무엇을 공유하며 무엇을 따로 가지는가? |
| OS-03 | 실행 상태와 문맥 교환 | 실행·준비·대기, 선점, 문맥 전환 비용 | 스레드가 존재해도 CPU를 사용하지 않는 이유는? |
| OS-04 | 스케줄링 | 응답성·공정성·처리량, 대표 정책과 기아 | 짧은 작업 우선이 항상 좋은가? |
| OS-05 | 프로세스 간 통신 | 파이프·소켓·공유 메모리의 역할과 비용 | 공유 메모리를 쓰면 동기화가 필요 없어지는가? |
| OS-06 | 경쟁 상태와 임계 구역 | read-modify-write, 원자성, 실행 순서 | 공유 변수 증가가 왜 하나의 원자적 작업이 아닐 수 있는가? |
| OS-07 | 동기화 도구 | 뮤텍스·세마포어·조건 변수, 대기·깨우기 | 락을 잡는 범위가 커지면 어떤 비용이 생기는가? |
| OS-08 | 교착상태와 진행 보장 | 발생의 필요 조건, 예방·회피·탐지·복구, 기아·라이브락 | 락이 여러 개라도 획득 순서를 통일하면 무엇이 달라지는가? |
| OS-09 | 가상 메모리와 주소 변환 | 가상·물리 주소, 주소 공간, 보호·공유, MMU | RAM이 충분해도 가상 메모리가 필요한가? |
| OS-10 | 페이징과 메모리 부족 | 페이지·페이지 테이블·TLB, 페이지 폴트, 교체, 스래싱 | 페이지 폴트가 항상 디스크 읽기를 의미하는가? |
| OS-11 | 파일과 영속성 | 파일·디렉터리·메타데이터, 버퍼링, 쓰기와 영속화의 차이 | write 성공 직후 전원이 꺼져도 데이터가 보존되는가? |
| OS-12 | I/O와 실행 모델 | blocking·nonblocking, synchronous·asynchronous, CPU·I/O-bound | 비동기와 논블로킹이 같은 뜻인가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
