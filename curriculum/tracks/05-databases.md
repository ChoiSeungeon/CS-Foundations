# 데이터베이스

기초 회차의 필수 영역이다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: CMU-DB, MYSQL, MYSQL-INDEX, MYSQL-TX. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| DB-01 | 관계 모델과 제약 | 테이블·행·열, 후보키·기본키·외래키, 무결성 | 기본키와 외래키는 각각 어떤 오류를 막는가? |
| DB-02 | 정규화와 모델링 | 함수 종속, 변경 이상, 1·2·3정규형, 반정규화의 비용 | 테이블을 분리할수록 항상 좋은가? |
| DB-03 | SQL과 NULL | 조건·집계·그룹·정렬, NULL과 3값 논리 | NULL과의 비교가 일반 값 비교와 다른 이유는? |
| DB-04 | 조인과 관계 연산 | INNER·OUTER JOIN, 중복 결과, 서브쿼리와 EXISTS | LEFT JOIN 뒤 WHERE 조건이 결과를 바꿀 수 있는가? |
| DB-05 | 저장 구조와 버퍼 | 페이지·행, 디스크 I/O, 버퍼 풀, 행·열 저장의 취지 | DB 캐시가 있어도 디스크 구조를 알아야 하는 이유는? |
| DB-06 | 인덱스의 원리와 비용 | 보조 자료구조, B+트리·해시, 읽기·쓰기·공간 비용 | 모든 컬럼에 인덱스를 만들면 왜 손해일 수 있는가? |
| DB-07 | 복합 인덱스와 조회 패턴 | 컬럼 순서, 범위 조건, 선택도, 커버링 | 같은 컬럼의 인덱스라도 순서가 다르면 결과가 달라지는가? |
| DB-08 | 쿼리 계획과 조인 비용 | EXPLAIN, 스캔·접근 경로, 통계, 조인 방식의 취지 | 인덱스가 존재해도 전체 스캔을 선택할 수 있는가? |
| DB-09 | 트랜잭션과 ACID | 원자성·일관성·격리성·지속성, 커밋·롤백, 자원 경계 | DB 롤백으로 이미 보낸 외부 요청도 되돌릴 수 있는가? |
| DB-10 | 격리 수준과 동시 실행 | dirty read·nonrepeatable read·phantom·lost update, 격리의 비용 | 트랜잭션 두 개가 같은 잔액을 읽고 저장하면 무엇이 달라지는가? |
| DB-11 | 락과 충돌 제어 | 공유·배타 락, 락 범위·순서, 낙관·비관 제어 | 락을 적용해도 교착상태는 생길 수 있는가? |
| DB-12 | MVCC와 읽기 | 버전·스냅샷, 일관 읽기·잠금 읽기, 구현별 차이 | 같은 트랜잭션에서 읽는 방식에 따라 보이는 값이 달라질 수 있는가? |
| DB-13 | 로그와 장애 복구 | WAL의 취지, redo·undo, 체크포인트, 백업과 복구 | 커밋 응답 전후에 서버가 멈추면 무엇을 확인해야 하는가? |
| DB-14 | DB 사용과 연결 관리 | 연결 풀, 트랜잭션 길이, 페이지네이션, N+1, 복제·분할의 입문 | 연결 풀을 키우면 DB 처리량도 항상 증가하는가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
