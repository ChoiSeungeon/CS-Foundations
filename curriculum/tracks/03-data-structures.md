# 자료구조·복잡도

기초 회차의 필수 영역이다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: CS50, MIT-DS. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| DS-01 | 복잡도와 분석 조건 | 시간·공간 복잡도, Big-O, 최악·평균·분할상환 | 평균 O(1)이 항상 같은 실행 시간을 뜻하는가? |
| DS-02 | 배열과 동적 배열 | 연속 배치, 인덱스 접근, 확장과 복사 | 동적 배열 추가는 왜 분할상환 O(1)이라고 하는가? |
| DS-03 | 연결 리스트 | 노드·참조, 단일·이중 연결, 탐색과 변경 비용 | 삽입할 위치를 모르면 연결 리스트가 여전히 유리한가? |
| DS-04 | 스택과 큐 | LIFO·FIFO, 추상 자료형과 구현의 구분 | 큐를 배열로 구현할 때 앞 원소 제거 비용을 어떻게 줄이는가? |
| DS-05 | 해시 테이블 | 해시 함수, 버킷, 충돌, 부하율과 재해싱 | 키가 같은 버킷에 몰리면 조회 비용은 어떻게 달라지는가? |
| DS-06 | 트리와 순서 | 트리 용어, 이진 탐색 트리, 편향과 균형 | 정렬된 입력을 그대로 넣으면 탐색이 느려질 수 있는가? |
| DS-07 | 힙과 우선순위 큐 | 힙 성질, 삽입·최솟값 제거, 정렬 배열과 비교 | 힙에서 임의 값 검색도 빠른가? |
| DS-08 | 그래프 표현 | 정점·간선, 유향·무향, 인접 행렬·리스트 | 희소 그래프에서 저장 방식을 어떻게 고르는가? |
| DS-09 | 그래프 순회 | BFS·DFS, 방문 관리, 큐·스택과 연결 | 최단 경로를 찾을 때 BFS를 쓸 수 있는 조건은? |
| DS-10 | 탐색 원리 | 선형·이진 탐색, 정렬 조건, 탐색 공간 축소 | 연결 리스트에서도 이진 탐색이 배열처럼 효율적인가? |
| DS-11 | 정렬 원리 | 대표 비교 정렬, 안정성, 제자리·외부 정렬의 취지 | 이미 정렬된 데이터와 메모리가 부족한 데이터의 선택은 같은가? |
| DS-12 | 자료구조 선택과 불변식 | 조회·추가·삭제·순서·중복·메모리의 절충 | 조회가 빠른 구조가 모든 요구에서 좋은가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
