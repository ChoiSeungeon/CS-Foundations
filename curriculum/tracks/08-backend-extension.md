# 백엔드·대용량 처리 확장

기초와 연결하는 확장 영역이다. 단기 면접 준비의 추가 필수 분량으로 만들지 않는다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: SPRING, KAFKA, REDIS; 주제별 추가 원문 선정 필요. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| EXT-01 | Spring 실행 경계 | IoC·DI·프록시, 요청 처리, 트랜잭션 적용 경계 | 같은 클래스 내부 호출에서도 프록시 기반 동작이 적용되는가? |
| EXT-02 | DB 접근 계층 | JDBC·ORM·영속성 컨텍스트·조회 전략, N+1의 관찰 | 객체 관계를 탐색하는 것과 SQL 실행은 언제 연결되는가? |
| EXT-03 | 캐시 전략과 무효화 | cache-aside·TTL, stale data, hit ratio, stampede | 캐시를 삭제한 직후에도 오래된 값이 돌아올 수 있는가? |
| EXT-04 | 큐와 메시징 | 생산·소비, 파티션·순서, 오프셋, 전달 보장 | 브로커에 저장됐다는 사실이 업무 처리 완료를 뜻하는가? |
| EXT-05 | 재처리와 멱등성 | 이벤트 식별자, 중복 방어, 재시도·DLQ, 만료 | 중복 방어 표식이 사라진 뒤 같은 이벤트가 도착하면? |
| EXT-06 | 정산과 이벤트 발행 | DB와 외부 시스템의 실패 창, outbox, 복구 인계 | DB 기록과 메시지 발행 사이에서 멈추면 무엇이 남는가? |
| EXT-07 | 실행 여력과 적체 | bounded queue, backpressure, 스레드·연결 풀, 거부 | 소비 속도만 높이면 시스템 전체 처리량도 높아지는가? |
| EXT-08 | 분산 환경의 데이터 | 복제·파티셔닝, 일관성·가용성, CAP의 전제 | 분산 환경에서 단일 프로세스의 락만으로 충분한가? |
| EXT-09 | 확장과 장애 격리 | 로드밸런싱, 수평·수직 확장, rate limit, circuit breaker | 인스턴스를 늘려도 공유 DB가 병목이면 어떻게 되는가? |
| EXT-10 | 성능 실험 | 부하 모델, warmup, p50·p95·p99, 병목·오류율 | 평균 응답 시간만 줄었다면 성능이 좋아졌다고 할 수 있는가? |
| EXT-11 | 컨테이너와 실행 환경 | 이미지·컨테이너, 프로세스 격리, 볼륨·네트워크, 자원 한도 | 컨테이너를 지워도 데이터가 남는 조건은? |
| EXT-12 | 프로젝트 검증 | 가정·선택·실패·근거·한계, 재현 가능한 작은 검증 | 직접 검증한 것과 설계상 기대한 효과를 어떻게 구분하는가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
