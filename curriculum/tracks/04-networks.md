# 네트워크

기초 회차의 필수 영역이다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: KUROSE, CS50. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| NET-01 | 계층과 캡슐화 | 인터넷 계층, 프로토콜, 헤더, 계층별 책임 | HTTP 오류와 TCP 연결 실패를 어떻게 구분하는가? |
| NET-02 | 주소와 전달 | MAC·IP·포트, 서브넷·게이트웨이, ARP의 취지 | 같은 서버의 여러 서비스는 어떻게 구분하는가? |
| NET-03 | 라우팅과 NAT | 패킷 전달과 경로 선택, 공인·사설 주소, NAT | 사설 IP만으로 인터넷에서 직접 접근할 수 있는가? |
| NET-04 | DNS | 이름 해석, 재귀·반복 질의, 캐시·TTL | DNS 변경이 모든 사용자에게 즉시 반영되는가? |
| NET-05 | TCP와 UDP | 연결·데이터그램, 스트림, 제공 보장과 제공하지 않는 보장 | TCP를 사용하면 애플리케이션 처리 성공까지 보장되는가? |
| NET-06 | TCP 연결과 종료 | 연결 수립·종료, 상태, TIME_WAIT의 취지 | 연결을 자주 새로 만들면 어떤 비용이 생기는가? |
| NET-07 | TCP 전송 제어 | 순서·ACK·재전송, 흐름 제어와 혼잡 제어 | 수신자가 느린 경우와 네트워크가 혼잡한 경우가 같은가? |
| NET-08 | HTTP 기본 의미 | 요청·응답, 메서드·상태 코드·헤더, 안전성·멱등성 | 응답을 못 받았다고 요청이 실행되지 않았다고 볼 수 있는가? |
| NET-09 | HTTP 연결과 버전 | 지속 연결, HTTP/1.1·2·3의 핵심 차이 | HTTP/2를 쓰면 모든 종류의 대기 문제가 사라지는가? |
| NET-10 | TLS와 HTTPS | 암호화·무결성·상대 인증, 인증서, 연결 흐름 | HTTPS라면 서버에 저장된 데이터도 자동으로 안전한가? |
| NET-11 | 웹 상태와 캐시 | 쿠키·세션, HTTP 캐시·재검증, 프록시·CDN의 역할 | 캐시 유효기간 중 원본이 바뀌면 무엇을 고려해야 하는가? |
| NET-12 | 통합 흐름과 관찰 | URL부터 응답까지, 소켓, 지연·대역폭·처리량, 타임아웃 | 응답이 느릴 때 DNS·연결·서버 처리 시간을 어떻게 나누는가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
