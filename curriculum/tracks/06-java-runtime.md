# Java·실행 환경

기초 회차의 필수 영역이다. 정답으로 답했던 주제도 전체 학습 과정을 거친다.

기준 자료 키: DEVJAVA, JLS, JVMS. [자료 목록](../../docs/sources.md). 각 수업에서 실제 절을 선정·확인한다.

| ID | 주제 | 학습할 범위 | 조건을 바꿔 설명할 질문 예시 |
|---|---|---|---|
| JAVA-01 | 값·참조·매개변수 전달 | 기본형·참조형, null, Java의 값 전달 | 메서드 안에서 참조 변수를 교체하면 호출자 변수도 바뀌는가? |
| JAVA-02 | 객체지향과 다형성 | 캡슐화·추상화·상속·다형성, 상속과 조합 | 상속 관계 없이도 다형성을 활용할 수 있는가? |
| JAVA-03 | 인터페이스와 타입 | 인터페이스·추상 클래스, 오버로딩·오버라이딩, 동적 디스패치 | 변수의 선언 타입과 실제 객체 타입이 다르면 무엇이 결정되는가? |
| JAVA-04 | 동일성·동등성 | ==·equals·hashCode 계약, 변경 가능한 키 | equals만 재정의하면 해시 컬렉션에서 무슨 문제가 생기는가? |
| JAVA-05 | 불변성과 문자열 | String·StringBuilder, 불변 객체, 방어적 복사 | final 참조라면 그 객체의 내부 상태도 불변인가? |
| JAVA-06 | 컬렉션 | List·Set·Map, ArrayList·LinkedList·HashMap·TreeMap의 선택 | 빠른 조회와 정렬 순서를 함께 요구하면 무엇을 바꿔야 하는가? |
| JAVA-07 | 제네릭과 타입 안전성 | 타입 매개변수, 불공변, 와일드카드, 소거의 취지 | List 하위 타입 관계가 원소 타입 상속과 같지 않은 이유는? |
| JAVA-08 | 예외와 자원 관리 | checked·unchecked, 예외 전파, try-with-resources | 예외를 잡고 무시하면 호출자는 무엇을 잘못 판단할 수 있는가? |
| JAVA-09 | JVM 실행과 메모리 | 바이트코드·클래스 로딩·JIT, 스택·힙, 스레드별·공유 영역 | 객체와 참조를 모두 스택 또는 힙 하나로만 설명할 수 있는가? |
| JAVA-10 | GC와 메모리 문제 | 도달 가능성, 회수·일시 정지, 누수·OOM, 관찰 지표 | GC가 있는데도 메모리 누수가 생길 수 있는가? |
| JAVA-11 | 동시성과 메모리 모델 | 가시성·원자성·순서, happens-before, synchronized·volatile·atomic | volatile 변수의 증가가 원자적이지 않을 수 있는 이유는? |
| JAVA-12 | 실행기와 비동기 작업 | 스레드 풀·큐·거부 정책, Future·CompletableFuture, 취소·예외 전파 | 작업 제출 성공이 실행 성공을 의미하는가? |

질문은 학습 범위의 일부 예시다. 예시 한 문제를 맞혔다고 해당 행을 완료하지 않는다. 이 표를 여러 문제 한꺼번에 제시하는 진단지로 사용하지 않고 질문은 하나씩 진행한다.
