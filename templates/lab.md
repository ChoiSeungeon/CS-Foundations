# 실험 이름

- 연결 ID:
- 질문·가설:
- 실제 실험 / 교육용 시뮬레이션 구분:
- 모델의 가정·생략 / 실제 구현과의 차이:
- 계획 시간: 준비 / 실행 / 해석 포함
- 환경과 버전:
- 수행 주체: 학습자 / AI / 함께

## 실행 전 예측: 학습자 답변

## 준비와 실행

필요한 최소 명령, 샘플 데이터, 실제 결과의 저장 위치. Windows와 Cloud 차이가 있으면 별도 표시.

## 실제 관찰

가정값·시뮬레이션의 표시 값과 실제 실행·측정값을 구분한다.

실행하지 않았다면 미실행으로 기록. 단일 실행 결과를 성능의 일반적 증거로 쓰지 않는다.

## 해석: 학습자 답변

예측과 차이 / 조건과 한계 / 원문 근거.

## 재현과 초기화

실험 전용 데이터만 초기화한다. 개인·프로젝트 DB의 기존 데이터를 지우지 않는다.
