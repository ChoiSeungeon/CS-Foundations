# 세션 기록

실제 학습 후 `YYYY-MM-DD-01.md` 형태로 templates/session.md를 복사한다. 같은 날 여러 세션이면 번호를 늘린다. 학습 전에는 수행 기록을 생성하지 않는다. 첫 기록은 [2026-11-03](2026-11-03-01.md)이다.

학습 질문에 대한 실제 답변은 `YYYY-MM-DD-01-answers.md`에 질문 맥락과 함께 원문으로 보존하고, 세션 기록에서 연결한다. 표현을 고친 수정안은 원문과 구분해 주제 노트에 남긴다. 첫 [답변 원문 기록](2026-11-03-01-answers.md)에는 22건의 답변과 해당 메시지의 추가 질문이 있다.
