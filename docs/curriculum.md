# 전체 학습 목차

핵심 7개 영역 **84개 주제**, 별도 확장 **12개 주제**로 구성한다. 주제 개수는 학습일 수나 완강 시간을 뜻하지 않는다. 한 주제를 여러 세션에 나누거나 한 세션에서 여러 주제의 관계를 살펴볼 수 있다.

초기 진단의 정답·오답과 관계없이 핵심 전 주제를 다룬다. 모르는 주제만 추려 학습하지 않는다. 읽기·정의·원리·예시·조건 변화·원문 확인·간격 복습을 주제별로 추적한다.

## 선수 관계와 순환

- ARCH-01~06 → OS의 실행·주소 공간, JAVA의 메모리. CPU 캐시와 DB/애플리케이션 캐시를 구분한다.
- DS-01~05 → DB 인덱스와 JAVA 컬렉션. 해시의 평균 비용·충돌 조건을 다시 연결한다.
- OS-02/06/07 → JAVA-11/12 → DB의 동시 실행. 프로세스 락과 DB 락을 동일시하지 않는다.
- NET-01~08 → SE의 API·인증·세션 → EXT의 요청 처리·메시징.
- DB-09~13와 NET의 실패·타임아웃 → EXT의 재처리·outbox.
- SE 테스트·관찰은 실험과 모든 영역에 함께 적용한다.

선수 개념이 부족하면 짧은 연결 설명을 먼저 하고 해당 선수 주제도 진도표에 남긴다. 다른 영역을 모두 끝낼 때까지 새로운 영역을 막는 엄격한 선형 순서는 아니다.

## 챕터와 세션

챕터는 OS-02처럼 핵심 주제 한 묶음으로 잡고, 연결할 ID와 이번 목표를 명시한다. 한 챕터는 여러 세션에 나눌 수 있다. 전체 지도를 먼저 설명한 뒤 개념·원리·시각 예시·원문을 학습하고 적용형·면접형 질문으로 확인한다. 질문 3~4개나 세션 한 번을 주제 완료와 동일시하지 않는다. 세부 흐름과 평가는 [학습 규칙](study-policy.md)을 따른다.

## 주제마다 남길 산출물

학습 종료 시 주제 노트에 지도·정의·원리·교사 시연·조건 변화·출처·실제 답변과 지원 여부·남은 목표를 모은다. 세션 기록과 진도표는 그 노트를 링크한다. 실험은 필요한 주제에만 별도 파일로 남긴다. 수업 전에 장문의 완성 노트를 AI가 전부 만들어 놓고 학습한 것으로 처리하지 않는다.

## 범위 변경

이 목차는 면접 대비용 기초와 Java 실행 환경을 중심으로 구성한 1차 범위다. 형식언어·컴파일러 제작·심화 이산수학·암호학·전문 분야 전체를 포괄하지 않는다. 필요성이 생기면 추가하되 기존 주제 ID를 조용히 지우거나 완료 처리하지 않는다. EXT는 관심 분야 확장이며 기초 범위를 대체하지 않는다.
