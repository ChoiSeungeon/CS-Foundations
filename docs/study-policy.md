# 학습과 평가 규칙

## 모든 주제에 적용하는 필수 과정

1. 사전 설명: 현재 이해를 짧게 확인한다. 초기 진단 정답이라도 생략하지 않는다.
2. 개념: 정확한 정의와 범위를 확인한다. 유사 용어와 다른 점을 구분한다.
3. 원리: 입력·상태·처리·결과를 구체적 예시로 추적한다. 비유와 실제 구현의 차이를 밝힌다.
4. 조건 변화: 부하·크기·실패·순서·동시성 등 조건을 바꿔 이유를 설명한다.
5. 확인: 해당 원문을 대조하거나 필요할 때 작은 실험을 수행한다.
6. 재설명: 학습자가 자료 없이 설명한다. AI가 대신 쓴 답변은 학습자의 증거가 아니다.
7. 간격 복습: 다른 날짜/세션에서 다른 예시로 다시 확인한다.

실험은 모든 주제의 의무가 아니다. 원리 이해에 실험이 유효한 경우 선택한다. 이미 아는 주제는 1~6을 짧게 진행할 수 있지만 어떤 단계도 정답을 이유로 생략하지 않는다.

## 진도 상태: tracking/progress.md에서만 변경

| 상태 | 의미 | 올릴 때 필요한 근거 |
|---|---|---|
| N0 | 정규 학습 미시작 | 초기 진단이 있어도 여기서 시작 |
| N1 | 학습 진행 중 | 개념·예시를 다뤘다는 세션 링크 |
| N2 | 기본 원리 설명 확인 | 필수 과정 1~6 중 기본 설명에 해당하는 목표를 확인한 학습자 답변, 검증한 출처 |
| N3 | 조건 변화 설명 확인 | 앞 단계와 함께 해당 주제의 필수 과정 1~6 모두 확인, 서로 다른 조건 변화 2개에 대한 이유 설명 |
| N4 | 간격 복습 확인 | N3 이후 다른 세션에서 다른 예시로 핵심·적용을 재확인 |

- N2·N3는 완료가 아니다. N4도 영구 숙달을 보장하지 않는다. 복습에서 흔들리면 근거를 남겨 보완 상태로 내릴 수 있다.
- 한 주제 안에 학습 목표가 여러 개면 미확인 목표를 노트에 남기고 단계 상승을 제한한다.
- 주제별 상태와 영역 전체의 상태를 혼동하지 않는다. 목차를 읽은 것은 학습 완료가 아니다.
- 진단·설명 청취·실험 관찰·자기 설명을 구분한다. 서로 다른 증거다.
- 출처 검증이 불가능했다면 노트에 `검증 대기`를 표시하고 N2 이상으로 올리지 않는다.

## 시간 운영

기본 60분: 회상 10분 + 개념·예시 25분 + 조건 변화·검증 15분 + 기록 10분. 단계는 세션을 넘겨 이어갈 수 있다. 짧은 질문 한 개의 답을 받는 턴 하나가 하루 수업 전체를 뜻하지 않는다.

추가 30분: 전체 목차에서 공백 확인 또는 꼬리 질문·짧은 원문. 추가 60분: 준비 포함 실험 또는 혼합 연습. 늘어난 시간만큼 다음 날 필수 분량을 늘리지 않는다. 결석한 날의 분량은 빚으로 쌓지 않는다.

## 복습

처음 배운 뒤 다음 학습일·약 1주 뒤·약 3주 뒤를 초기 복습 후보로 둔다. 실제 일정과 답변에 따라 바꾼다. 간격은 고정 과학적 보장이 아닌 운영 규칙이다. 후보 날짜를 넘겼다고 몰아서 수행하지 않고 우선순위가 높은 항목부터 제한된 시간에 확인한다.

정의 반복 외에 오개념 교정·조건 변화·다른 영역과 연결을 섞는다. 답변을 먼저 받은 뒤 피드백한다. 미확인 항목을 완료 처리하지 않는다.

## 자료와 정확성

수업마다 원문 URL, 절 제목, 확인일과 적용 버전을 notes/에 남긴다. docs/sources.md는 출처의 입구이지 모든 절의 검증이 끝났다는 표시가 아니다. 무료 목차를 기준으로 누락을 점검하되 출처의 강의·과제 전체를 의무 수강하지 않는다.

AI가 정의를 임의로 바꾸지 않도록 일반 원리/구현별 차이/실험 조건을 나눠 설명한다. 단일 예시만으로 일반화하지 않는다. 영어 원문은 짧게 발췌·해설하며 번역만으로 검증을 대신하지 않는다.
