# 학습자 맥락

마지막 확인: 2026-11-02, Asia/Seoul. 아래는 학습 계획 수립 대화에서 학습자가 제공한 정보입니다. 새 채팅은 이 파일을 통해 맥락을 이어받습니다.

## 목표

- 기본 CS 전반을 탄탄하게 이해하고, 조건이 바뀐 꼬리 질문에도 이유를 설명한다.
- 백엔드·대용량 트래픽에 관심이 있으나 학습 범위를 그 분야에 한정하지 않는다.
- Velog에 공부한 내용을 기록한다. 블로그에는 CS 외의 글도 올라갈 예정이다.
- 기록을 면접 복습과 취업 포트폴리오로 활용한다.
- GitHub는 학습 기록·코드를 두 컴퓨터 사이에서 이어가고 별도의 Codex Cloud 채팅에 맥락을 전달하는 데 사용한다.

## 경험과 선호

- 컴퓨터공학 전공 수업·시험 중심으로 공부했다. 마지막 집중 CS 학습은 약 1년 전 정보처리기사 준비였다.
- 기술 면접 경험은 없다. 지원은 계속한다. CS 완성을 기다린 뒤 지원하려는 것이 아니다.
- 예시를 통해 이해하고 질문·답변을 주고받는 방식을 선호한다. 질문은 가능하면 한 번에 하나.
- 책 구매보다 무료 자료를 선호한다. AI가 범위를 누락하거나 부정확하게 설명하는 것을 우려한다.
- 영어 독해에는 시간이 걸리지만 짧은 영어 원문과 번역·설명을 함께 활용하는 데 동의한다.
- 기록 경험은 없다. 매번 공개 글 완성을 요구하지 않는다.
- 코딩 테스트 준비는 별도로 하며 이 학습 시간에 포함하지 않는다.

## 시간과 환경

- 하루 1시간을 기본으로 하며 추가 학습도 가능하다. 다른 일정 때문에 못 하는 날도 있다.
- SSAFY 중 추가 시간이 생길 수 있으나 보장되지 않는다. 확정된 하루 2시간 일정으로 만들지 않는다.
- 저녁에는 개인 노트북, 그 외에는 SSAFY 컴퓨터를 사용할 수 있다.
- Java·Eclipse·STS·MySQL·Docker가 설치되어 있고 프로젝트에서 사용한 경험이 있다. 버전은 미확인이다.
- 두 컴퓨터에서 개인 GitHub 저장소 clone·push가 가능하다고 답했다.
- 실제 수업은 이 계획을 만든 로컬 채팅이 아니라 다른 Codex Cloud 채팅에서 진행할 예정이다.

- 위 날짜 이후에 새 채팅을 시작하면 결과를 추정하지 말고 실제 상태를 확인하거나 일반 학습을 계속한다.

## 반드시 지킬 결정

- 정답으로 답한 개념도 정규 학습에서 생략하지 않는다.
- 초기 오답만으로 좁은 학습 범위를 만들지 않는다. 전체 목차를 기준으로 순환한다.

- 장기 기간을 학습 완료 보장이나 면접 준비의 선행 조건으로 제시하지 않는다.
