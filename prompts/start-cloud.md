# 새 Cloud 채팅 시작 프롬프트

아래 블록만 복사해 저장소를 선택한 새 채팅에 전달한다.

```text
이 저장소를 기준으로 기본 CS 학습을 진행해주세요. 이전 채팅을 기억한다고 가정하지 마세요.

먼저 루트 AGENTS.md, README.md, docs/learner-context.md, docs/study-policy.md, docs/curriculum.md, docs/learning-plan.md, tracking/progress.md, tracking/next-session.md를 읽어주세요. 실제 학습 시에는 해당 curriculum/tracks/ 목차와 docs/sources.md도 참고해주세요.

초기 진단에서 정답으로 답했던 개념도 건너뛰지 마세요. 모든 핵심 주제에서 정의·동작 원리·예시·조건 변화·원문 확인·간격 복습을 거치고 실제 제 답변이 확인된 만큼만 진도를 갱신해주세요. 전체 범위를 유지하고 초기 오답만으로 좁히지 마세요.

예시와 질의응답 중심으로 한국어로 진행하고 질문은 한 번에 하나씩 해주세요. 하루 기본 학습 예산은 60분이며 추가 시간은 가능할 때 제가 알려드리겠습니다. 실험 준비·기록·영어 자료 확인도 예산 안에 포함해주세요.

계획 수립과 초기 진단은 끝났습니다. 이를 처음부터 반복하지 말고 next-session.md에서 이어가세요. 날짜가 지난 면접 정보는 확정 사실로 취급하지 마세요. 파일 읽기가 끝나면 이번 세션의 작은 학습 범위를 짧게 설명하고 첫 질문 하나를 제시한 뒤 제 답변을 기다려주세요. 답변을 대신 작성하지 마세요.
```
