# Velog 초안과 발행 기록

주제별 메모·질문·실험을 검증한 뒤 templates/velog-post.md로 초안을 작성한다. 학습 노트형·예시 설명형·실험형을 시도하며 형식을 정한다. CS 시리즈로 묶되 블로그 전체를 CS 전용으로 제한하지 않는다.

발행보다 이해·검증이 우선이다. 정답 진단이나 AI가 작성한 글만으로 학습 완료 처리하지 않는다. 면접 전 발행 의무는 없다. 발행은 사용자가 요청할 때 진행하며 이 파일은 자동 발행 설정이 아니다.

| 제목 | 연결 ID | 원본 노트·실험 | 상태 | Velog 링크 |
|---|---|---|---|---|

현재 초안·발행 글 없음. 일상 학습 기록을 매번 공개 글로 다듬지 않는다.
