# CS Study

기본 CS를 예시·질의응답·작은 실험으로 이해하고, 조건이 바뀌어도 이유를 설명하기 위한 개인 학습 저장소입니다.

백엔드·대용량 처리에 관심이 있지만 기초 CS 전반을 다룹니다. 면접 복습, Velog 글, 이후 포트폴리오로 연결합니다.

## 처음 시작할 때

1. [Cloud 시작·이동 안내](docs/cloud-handoff.md)를 확인합니다.
2. [전체 목차](docs/curriculum.md)에서 범위와 진행 순서를 확인합니다.
3. [학습 규칙](docs/study-policy.md)을 읽습니다. 초기 진단의 정답은 학습 완료가 아닙니다.
4. [현재 진도](tracking/progress.md)와 [다음 세션](tracking/next-session.md)을 확인합니다.
5. 새 채팅에서는 [시작 프롬프트](prompts/start-cloud.md)를 사용합니다.

## 파일의 역할

| 위치 | 역할 |
|---|---|
| AGENTS.md | Codex가 참고할 학습·기록 지침 |
| docs/ | 학습자 맥락, 계획, 전체 목차, 출처, 환경 간 인계 |
| curriculum/tracks/ | 영역별 세부 주제·학습 범위·조건 변화 질문 |
| tracking/ | 진도, 초기 진단, 다음 세션의 위치 |
| notes/ | 주제별 검증한 설명과 학습자 답변 |
| sessions/ | 학습일별 요약·실제 수행 내용·증거 |
| review/ | 간격 복습과 혼합 질문 |
| labs/ | 재현 가능한 작은 실험, 환경과 결과 |
| interview/ | 여러 영역을 섞은 면접 연습과 프로젝트 설명 |
| publishing/ | Velog 초안·발행 목록·원문과 실험 링크 |
| templates/ | 필요한 시점에 복사하는 최소 기록 양식 |
| prompts/ | 새 채팅 시작·재개·마무리용 문구 |

## 현재 상태

- 초기 대화의 표본 진단과 정규 학습을 구분합니다. 2026-11-03 첫 정규 학습을 진행했으며 현재 상태와 다음 학습 위치는 tracking/을 기준으로 합니다.
- 학습자의 답변을 보지 않고 진도를 진행하거나 학습 완료로 바꾸지 않습니다.
- 이 묶음은 GitHub에 올릴 파일입니다. Git 원격 저장소·Cloud 환경·Velog가 자동 생성되지는 않습니다.
- 추천 저장소 이름: `cs-study`. 개인 학습용 공개/비공개 여부는 사용자가 선택합니다.
- 채용 결과·개인정보는 올리지 않아도 됩니다. 현재 맥락 파일에는 회사명·연락처·원본 포트폴리오를 포함하지 않았습니다.

## 유지 방법

목차는 curriculum/tracks/, 상태는 tracking/progress.md, 재개 지점은 tracking/next-session.md를 기준으로 합니다. 같은 설명을 여러 파일에 중복 복사하기보다 원본 노트에 링크합니다. 빈 주제 노트 수십 개를 먼저 만들지 않고, 학습할 때 템플릿으로 생성합니다.
