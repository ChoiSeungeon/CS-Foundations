# CS Foundations

컴퓨터과학의 기본 개념을 구체적인 예시와 질문으로 이해하고, 그 과정을 기록하는 개인 학습 저장소입니다. 컴퓨터구조부터 운영체제·네트워크·데이터베이스·Java 실행 환경까지 다루며, 조건이 바뀌어도 동작 원리와 선택의 이유를 설명하는 것을 목표로 합니다.

개념 정리와 함께 실제 학습 답변, 혼동했던 부분, 수정한 설명과 복습 기록을 남깁니다. 백엔드와 대용량 처리에 필요한 기초를 쌓으면서 학습 범위를 넓혀갑니다.

## 학습 방법

각 주제에서 **정의 → 동작 원리 → 예시 → 조건 변화 → 원문 확인 → 본인 말로 재설명 → 간격 복습**을 진행합니다. 필요할 때 작은 실험을 추가합니다.

질문에 먼저 답한 뒤 피드백과 짧은 수정안을 받고, 다른 예시에서 다시 설명합니다. 예를 들어 캐시의 공간 지역성을 배웠다면 연속된 주소와 떨어진 주소를 읽는 상황을 비교해 이유를 설명합니다.

학습 진행은 실제 답변과 확인한 출처를 근거로 기록합니다. 기본 설명 확인과 조건 변화 설명, 이후 복습 확인을 구분하며 세부 기준은 [학습 규칙](docs/study-policy.md)에 남깁니다.

## 출처와 작성 방식

공개 강의와 공식 문서를 참고하며, 실제로 확인한 원문의 URL·절·확인일과 적용 조건을 주제 노트에 남깁니다. 일반 원리와 특정 구현의 동작을 구분하고, 설명을 위한 예시와 실제 실험 결과도 구분합니다.

학습과 정리에는 AI의 도움을 활용합니다. 학습자가 직접 작성한 답변과 AI가 보충·수정한 설명을 구분하여, 이해가 바뀐 과정을 확인할 수 있도록 기록합니다. 내용은 학습과 검증에 따라 보완합니다.
